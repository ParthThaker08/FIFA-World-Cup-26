# ⚽ FIFA World Cup 2026 Tracker

A fully self-contained, single-file tracker for all 104 matches of the 2026 FIFA World Cup.
No frameworks. No build tools. No dependencies. Just open the HTML file.

## Features

- **📅 Schedule** — All 104 matches grouped by day, with live countdown to next kick-off
- **📊 Groups** — Standings table for all 12 groups (A–L), updated as the tournament progresses  
- **🏆 Knockout Bracket** — Full R32 → R16 → QF → SF → Final bracket with SVG connector lines
- **🌙 Dark / Light mode** — Toggle with one click
- **🕐 Time zone support** — Convert all match times to your local time zone
- **🔍 Filters** — Filter by city, group, or team name

## Usage

No installation needed. Just download `index.html` and open it in any browser.

```bash
git clone https://github.com/parththaker/worldcup2026.git
open index.html
```

## Tech

Pure HTML, CSS, and vanilla JavaScript — everything in a single file.
Absolute-positioned SVG bracket with mathematically exact connector lines.
